# 🧠 NotesHub AI

Upload • Learn • Chat • Succeed

## Overview

NotesHub AI is an AI-powered learning platform that helps students upload, organize, search, and study notes efficiently.

### Current Features

- JWT Authentication
- User & Admin Dashboard
- Upload Notes
- Download Notes
- Search Notes
- Categories
- Profile Management
- Cloudinary Image Upload
- Responsive UI

### Upcoming AI Features

- AI Summary
- AI Quiz Generator
- AI Flashcards
- AI Chat with PDF
- AI Study Planner
